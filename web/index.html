Додати Worker

      

        

        

        

      

      

        

          Оберіть роль для нового вузла. Роль визначає, які компоненти будуть
          встановлені.
        

        
        

          Після підключення вузол автоматично отримає можливості (capabilities)
          залежно від його обладнання.
        

      

      

        

          Одноразовий токен діє 15 хвилин. Скопіюйте його та введіть на новому
          вузлі під час First Run Wizard, або використовуйте installer command
          нижче.
        

        
Генерація токена…

        
        
Installer Command

        
curl -fsSL https://raw.githubusercontent.com/fylypovych/vertep/main/bootstrap.sh | sudo bash

        

          Після запуску bootstrap виберіть відповідну роль у Web Wizard. Для
          non-Core вузлів вкажіть Core URL та Registration Token.
        

        
Push-based (автоматичне підключення)

        
VERTEP_ROLE=gpu curl -fsSL https://raw.githubusercontent.com/fylypovych/vertep/main/bootstrap.sh | sudo bash

        

          При push-based сценарії вузол автоматично підключиться до Core після
          встановлення. Переконайтеся, що на Core згенеровано відповідний
          Registration Token.
