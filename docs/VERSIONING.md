# Версіонування та публікація Vertep

Актуальні правила команд `пуш` і `реліз` визначено в [AGENTS.md](../AGENTS.md#3-версіонування-push-та-release).

Завдання щодо версіонування й release workflow ведуться в [GitHub Issues](https://github.com/fylypovych/vertep/issues). Старий план виправлення нумерації скасовано; історію commit і наявні tags не переписувати.
