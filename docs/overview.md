# Vertep — огляд

> Статус: чинний | Аудиторія: усі | Канон: `AGENTS.md` §1, §4

Vertep — оркестратор автоматизованої фабрики короткого медіаконтенту з віртуальними персонажами.

Ключовий принцип:

> Vertep **не генерує контент** — він керує інструментами, які генерують контент. Вертеп — це конвеєр. Моделі змінюються. GPU змінюються. Workflow змінюються. Персонажі додаються й закриваються. А Vertep залишається центральною системою.

## Що робить система

1. Приймає тему (перше джерело — Telegram; далі — RSS, сайти, API, ручне створення).
2. Генерує сценарій на Text Node (LLM) і затверджує його з користувачем.
3. Генерує розкадрування та зображення на GPU Node (ComfyUI), затверджує.
4. Синтезує голос на Voice Node (TTS).
5. Монтує фінальне відео (FFmpeg) і показує на review; підтримує revision-версії.
6. Публікує затверджене відео через Publisher Node (YouTube, TikTok, Facebook, Instagram, Threads) або Telegram.
7. Зберігає jobs, history, artifacts, receipts; переживає рестарти, оновлення й відновлення з backup.

## Хто виконує роботу

- **CORE** — мозок і диспетчер: jobs, tasks, черги, стан, API, Web UI. Контент не генерує (див. `core-generation-gate.md`).
- **Worker-и** — руки: Text (Ollama/LLM), GPU (ComfyUI), Voice (TTS), Publisher (платформи), Backup, Monitoring. Кожен заявляє свої **capabilities**; диспетчер шукає вузол за capability, а не за роллю.
- **Движки** — змінні задні технології за формальними інтерфейсами (`providers.md`): сьогодні Ollama/ComfyUI/FFmpeg, завтра — інші, без зміни ядра.
