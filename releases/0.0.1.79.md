# Vertep 0.0.1.79

## Rolling update: cancel cleanup + self-test binding

Очищення residual update-команд на worker-ах після cancel rollout: `_cleanup_cancelled_workers` видаляє `desired_state`, `update_target_version`, `update_operation_id`, `rollback_target_version`, `self_test_requested_at` з affected nodes. Self-test binding перевіряє `checked_at > phase_started_at` для запобігання stale PASSED результатам, що можуть помилково approve wrong target version.

## Monitoring: Prometheus scrape + alert rules

Розширено Prometheus scrape inventory: `vertep-core` (static), `vertep-workers` (DNS SRV discovery), `node-exporter`, `loki`, `prometheus` self-scrape. Додано алерти: `VertepJobFailureSpike`, `VertepDeadLetterTasks`, `VertepQueueBacklog`, `VertepWorkerOffline`, `VertepWorkerPartialOutage`, `VertepNodeExporterDown`.

## Update security: interrupt evidence detection

`_has_interrupt_evidence` виявляє durable evidence (audit.jsonl entries, pending request files) коли `status.json` нечитабельний або пошкоджений, запускає recovery замість silent failure. 6 нових тестів на edge cases: corrupt audit, empty evidence, unreadable status.

## Worker self-test: DISABLED/RESTARTING/REVOKED guard

`available_worker` виключає worker-ів з `desired_state` DISABLED/RESTARTING/REVOKED з претендентів на claim tasks, навіть якщо вони мають PASSED self-test.

## ComfyUI Docker: VideoHelperSuite

Додано ComfyUI-VideoHelperSuite (VHS) плагін до NVIDIA Docker image для підтримки video workflows.

## Web UI: typed DTOs migration

Типізовані DTO для workers/health, node/status, health/history, security/check, workflows, health metrics, security certificates; видалено `Record<string, unknown>` для цих доменів.
