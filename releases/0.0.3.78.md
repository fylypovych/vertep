# Vertep 0.0.3.78

- mTLS (#484, `i.0.0.4.84`): за `NODE_MTLS_REQUIRED=true` вузол автентифікується лише власним credential разом із перевіреним сертифікатом; спільний `NODE_API_TOKEN` у цьому режимі не приймається. Без mTLS спільний токен лишається сумісним fallback.
- Персонажі (#485, `i.0.0.4.85`): новий job через API чи Telegram за явним ID неповного персонажа (без усіх файлів §3.2) відхиляється з 422; читання наявних job не змінено; тестові фікстури доповнюють персонажів через `tests/character_files.py`.
- Bootstrap: першим етапом під час першої інсталяції запитує, що встановити — Vertep чи лабораторію Vertep (LAB); на сервері з уже встановленим Vertep або LAB оновлює встановлений продукт без питань; для автоматизації — `VERTEP_INSTALL_TARGET=vertep|lab`, без термінала ставиться Vertep.
- Bootstrap: роль із ComfyUI на хості без NVIDIA/AMD GPU (наприклад, Hyper-V VM без passthrough) одразу завершується зрозумілою помилкою замість циклічного перезапуску ComfyUI до таймауту health check; автоматичного переходу на CPU немає.
- CI `ubuntu-bootstrap-lifecycle`: прибрано тимчасовий виняток 0.0.3.77 — після публікації другого Release проба відкату знову обов'язкова.
- Аудит `audit/audit-1511.md`: незалежна звірка #469–#483 і перенесення залишків до #484/#485.
