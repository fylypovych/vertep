# Vertep 0.0.4.50

- Налаштування → Загальне: поле «Адреса панелі LAB» для необов'язкового підключення окремої лабораторії (#491 L2); адреса зберігається в конфігурації CORE (`lab-panel.json`) і лишається після перезавантаження, `LAB_PANEL_URL` з `.env` — запасне значення. Приймається лише `https://` без логіна, параметрів і фрагмента; змінює тільки адміністратор, зміна записується в аудит. Після збереження з'являється пункт «Лабораторія» і вхід у LAB через Vertep. web-ui — 0.0.4.28.
- API: `GET`/`PUT /api/settings/lab-panel`; `/api/lab/panel` і перевірка адреси повернення для входу в LAB використовують збережену адресу.
- Тести: збереження, перезавантаження, відмова для некоректних адрес і модератора, очищення адреси; сценарій налаштування в Playwright.
