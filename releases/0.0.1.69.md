# Vertep 0.0.1.69

## Мета
Виправлення двох тестів, які блокували release workflow на Linux CI.

## Зміни
- `tests/test_key_lifecycle.py`: `resign()` тепер використовує `copy.deepcopy(metadata)` замість `dict(metadata)`. Попередній shallow copy дозволяв зміну `release_keys` через повернений словник проникати в оригінальний `metadata`, що робило canonical невідповідним підписам і викликало `RuntimeError("Root metadata signature threshold was not met")` при подальшому `validate(metadata, ...)`.
- `tests/test_job_workspace_contracts.py`: `test_job_list_status_exact_filter` більше не викликає `cancel` (race condition з асинхронним pipeline). Тепер фільтрує за статусом, який сервер фактично призначив job при створенні.

## Перевірка
- `python -m compileall -q tests/`: OK.
- `pytest tests/test_key_lifecycle.py tests/test_job_workspace_contracts.py`: пропущені на Windows (немає openssl); повна перевірка на Linux CI.
