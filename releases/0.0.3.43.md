# Vertep 0.0.3.43

Причина несумісності Worker у панелі, стабільніший паралельний запуск тестів і метадані кореневого ключа.

- Worker: панель показує причину, чому несумісний Worker не отримує задач (#415).
- Тести: групування `xdist` у `conftest.py` тепер справді діє; раніше мітку ставили запізно, і тести Redis та процесні тести заважали одне одному (#413).
- Тести: `test_runner_browser_e2e` чекає перший клік до 120 с, бо під навантаженням сторінку довго закриває індикатор завантаження.
- CI: `fleet-rollout-acceptance` розбито на дві паралельні частини, усі 7 тестів збережено, звіт `criterion-390` читає обидві (#413).
- Оновлення: додано метадані кореневого ключа й відкриті ключі в `installer/root-keys` із дозволом для робочого ключа `release-1` (#418). `REQUIRE_OFFLINE_ROOT` лишається вимкненим.

Перевірка на реальному сервері не виконувалась.
