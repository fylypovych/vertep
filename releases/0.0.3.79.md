# Vertep 0.0.3.79

- Telegram (#486, `var.0.0.4.86`): вхідний бот запитів і публікація в канал розділені. Публікацію виконує окремий бот `TELEGRAM_PUBLISHER_BOT_TOKEN` (секрет `telegram_publisher_bot_token`). Канал Telegram тепер ціль публікації бренду — `Channel` типу `telegram` з `@назва` або числовим ідентифікатором. Загальне налаштування `telegram_channel_id` прибрано без автоматичної міграції: поки бренд не має увімкненого Telegram-каналу, публікація в Telegram має статус `NOT_CONFIGURED`. Задача публікації отримує лише токен бота-публікатора, токен вхідного бота їй недоступний. Readiness перевіряє право бота публікувати в кожному каналі брендів.
- Персонажі (#485, `i.0.0.4.85`): за рішенням власника видалено неповний тестовий персонаж `characters/char-contract/`; тест перевіряє, що всі персонажі в каталозі повні.
- Реліз (аудит 15.11, P3): `scripts/release.py` передає workflow `expected_sha`, і реліз зупиняється, якщо `main` змінився після перевірки gate. Release workflow публікує SBOM окремим asset `sbom-<версія>.cdx.json` (входить у `SHA256SUMS`). Якщо використано `skip_tests`, опис Release отримує позначку про пропущені тести.
- Publisher readiness (аудит 15.11, P3): `GET /api/tasks/publisher-readiness` працює через `providers.publisher()` (`PublisherProvider.readiness`), а не напряму через `PUBLISHERS`.
- Документація: таблиця `docs/core-generation-gate.md` §5 посилається на функції замість застарілих номерів рядків.
- Аудит `audit/audit-1511.md`: рішення власника щодо семи знахідок P3; `shell=True` у бекапах винесено в #488.
