# Vertep 0.0.1.92

## Task 1 — Audio contract/checksum обов'язковий
- `_persist_tts_contract` тепер відхиляє відсутній contract (не dict) та відсутній sha256 замість ігнорування.
- Pre-validation у `tasks.py` відхиляє TTS results без contract, sha256, provider або voice (HTTP 400).
- Duplicate TTS result обробляється ідемпотентно — повертає 200 замість 409.

## Task 2 — Controlled TTS lifecycle
- `TTS_GENERATING` та `TTS_READY` додані до restart recovery set у `pipeline.py` — після restart сцени повертаються до NEW.
- `_pending_voice_scenes` тепер включає PENDING сцени для коректного re-dispatch після worker loss.
- Приймання підтверджено 15 acceptance-тестами: contract mandatory (7), cancel/pause (2), duplicate (1), worker loss (1), restart recovery (2), metadata flow (2).
