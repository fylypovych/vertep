# Vertep 0.0.3.30

- Web UI: фонова перевірка вікна налаштування більше не розлогінює й не показує помилку; це усуває збій Browser E2E версії 0.0.3.29.
- Оновлення: адмінка показує фактичну версію, а не версію останньої спроби; тимчасова помилка 5xx під час дренажу більше не зупиняє оновлення.
- Черга: видалення Job прибирає його задачі, а після перезапуску CORE прибираються задачі раніше видалених Job.
- Сертифікат: новий самопідписаний сертифікат містить адресу, з якої зайшов адміністратор; bootstrap записує IP-адресу як IP; у Налаштування → Безпека можна завантажити сертифікат.
- Ролі: додаткові ролі оцінюються за контейнерами цього вузла; контейнери невибраних ролей не погіршують стан `core`; невибрані ролі показані як «Не вибрано».
