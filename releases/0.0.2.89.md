# Vertep 0.0.2.89

Версія виправляє блокувальні помилки CI та release `prepare`, які не дозволили завершити реліз `0.0.2.88` для точного SHA.

## Media acceptance CI

- Evidence-каталог створюється до запуску pytest, а `--basetemp` винесено в `$RUNNER_TEMP`.
- Тимчасові каталоги тестів більше не залежать від evidence-каталогу; помилка `FileNotFoundError ... runtime-tests` не виникає.
- Evidence, JUnit і артефакти залишаються в `media-evidence/<run>/`, тимчасові runtime-файли не потрапляють в артефакт.

## Release prepare

- `tests/test_apply_deployment_docker.py` задає реальний `HEALTHCHECK` тестовому worker, тому `wait_for_healthy` бачить фактичний health state, а не чекає 600 секунд на відсутній health.
- `tests/test_backup_process_acceptance.py` завершує disposable uvicorn процес із kill-fallback; завислий graceful shutdown під час симуляції crash не валить acceptance.
- `tests/test_workflow_postgres_state.py` запускає disposable PostgreSQL із власним каталогом unix socket (`-k`) і показує tail логу разом із причиною завершення процесу.

## Перевірки

- `compileall`, `git diff --check`, повний `pytest` і `scripts/release.py --check` виконані локально перед commit.
- Публікація — лише через GitHub Actions release workflow для версійного commit `0.0.2.89`.
