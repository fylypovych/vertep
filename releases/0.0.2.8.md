# Vertep 0.0.2.8

- Browser E2E CI: CORE запускається з `nohup` і логом у файл, щоб процес не гинув разом із pipe кроку після першого запиту.
- Browser E2E CI: `CONFIG_ROOT`, `STORAGE_ROOT`, `JOB_ROOT` перенесено в `$RUNNER_TEMP` з готовими `installation.json` та `users.json` — runner не має прав на `/data`, тому запис профілю, пароля й system-state падав.
- Browser E2E CI: додано крок pre-flight, який перевіряє вхід обох E2E-облікових записів і видимість каталогу system-state для запущеного CORE до запуску тестів.
- Browser E2E: перевірка блокування кнопки в READ_ONLY стала детермінованою через перезавантаження сторінки; таймаут UI-входу тепер повертає причину відмови сервера замість абстрактної помилки.
