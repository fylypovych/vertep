# Vertep 0.0.2.51

## Provider Switch End-to-End (Issue i.0.0.1.17)

Реалізовано повний цикл перемикання провайдера: CORE → збережені overrides (`provider-overrides.json`) → heartbeat Worker → executor environment → voice preview + effective config після restart.

- `core/provider_switch.py`: додано `effective_provider_config()`, `provider_executor_config()` — активний backend, persisted override, executor-env subset (тільки allowlisted, без секретів), прапор `configured`.
- `core/api/models.py`: endpoint перемикання повертає `effective_config`, `executor_config`; preview відхиляє switch, якщо executor ще не застосував (409 `executor`).
- `worker/service.py`: `apply_provider_config()` / `executor_provider_config()` — Worker застосовує heartbeat delivery до власного executor env; не-allowlisted ключі (secrets) ніколи не застосовуються.
- Тести: `test_provider_executor_config_carries_only_allowlisted_non_secrets`, `test_heartbeat_delivers_provider_config_to_the_worker`, `test_worker_applies_heartbeat_provider_config`, `test_preview_refuses_a_switch_that_missed_the_executor`, `test_switch_reaches_the_executor_and_drives_preview_and_restart` (loopback TTS runtime доводить end-to-end шлях).

## TTS Voice/Language/Provider/Model/Speed Catalog (Issue i.0.0.1.5)

Розширено voice catalog до повної readiness-матриці, яку dispatcher і Worker reconciliate end-to-end.

- `services/tts_service.py`: `_available_languages()` — підтримувані мови виводяться з встановлених голосів espeak-ng; `/voices` повертає `languages`, `providers`, `speed_range`; `SynthesisRequest` приймає `provider`/`model`/`language` (не гейтуються runtime, гейтуються на dispatch у CORE); `_validate_language()` відхиляє непідтримувану pinned мову 422 замість пізнього synthesis failure.
- `core/dispatcher.py`: `_voice_ready` — fail-closed перевірка voice catalog; порожній catalog більше не означає «приймає будь-що»; враховано language/provider/model/speed.
- `tests/test_voice_pipeline.py`: `test_dispatcher_selects_voice_worker_by_catalog` — перевірено повну readiness матрицю.
- `tests/test_tts_service.py`: нові тести language rejection/acceptance, extra fields acceptance.

## MoneyPrinterTurbo Submit Route Self-Test Proves Full §9.3 Scene Matrix (Issue #124)

Self-test більше не доводить лише один timestamp — він завантажує всі agreed probe сцени, кожна зі своїм кольором і тривалістю, і перевіряє скачаний артефакт кадр за кадром.

- `services/moneyprinter_service.py`: `check_submit_route()` — завантажує `PROBE_SCENES` матрицю, рендерить голос під сумарну тривалість, submit-route повертає `timeline` з `scenes[]` (`label`, `seconds`, `at_seconds`, `mean_colour`, `expected_colour`), `scene_order`, `expected_scene_order`, `aspect`, `fit_mode`, `concat_mode`, `expected_duration_seconds`.
- `scripts/moneyprinter-runtime-check.py`: `verify_self_test()` — gate відхиляє reorder/dropped/retimed scenes, mismatched clips (`drift > 48`), scenes поза timeline, відсутні compose fields.
- Тести: `test_runtime_check_requires_a_proven_submit_route` — перевірено всі негативні шляхи (порожній timeline, reorder, duration mismatch, compose fields, clip mismatch, out-of-bounds).

## Security Hardening

- `core/security.py`: `_session_token()` / `_valid_session()` — перевірка наявності `session_secret` (rejected forged sessions коли secret unset); `_authenticate_user()` / `_account_role()` — guard `ADMIN_PASSWORD` (never mint session коли unset); constant-time comparison для admin credentials.
- `tests/test_backend_contracts.py`: `test_unset_admin_password_never_mints_a_session`, `test_unset_session_secret_rejects_forged_session`.
