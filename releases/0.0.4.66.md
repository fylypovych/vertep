# Vertep 0.0.4.66

- LAB (#491 L2): панель лабораторії відкривається всередині Vertep у рамці — `GET /api/lab/frame` видає адміністратору адресу панелі з короткоживучим підписаним твердженням (`core/api/users.py`), сторінка «Лабораторія» вбудовує її з посиланням «Відкрити окремо» (`web-v2/src/app/lab/lab-entry.component.ts`); панель LAB дозволяє рамку лише собі й підключеному Vertep (`frame-ancestors` з `LAB_VERTEP_URL`, `deploy/lab/Dockerfile.web`, `deploy/lab/web/nginx.conf`, `deploy/lab/docker-compose.web.yml`).
- LAB: запити до CORE з закріпленим самопідписаним сертифікатом CORE (виданим при підключенні) більше не падають через невідповідність імені хоста — для саме цього сертифіката перевіряється лише він сам, справжній CA зберігає перевірку імені (`lab/tls.py`, `lab/gpu_lease.py`, `lab/identity.py`, `lab/role_service.py`, тест `tests/test_lab_tls_pinned_core.py`).
- Модулі на CORE: образ Персонажів копіює `knowledge_logic.py` (контейнер падав при старті); перевірка здоров'я Брендів і Моніторингу виконується через Python замість відсутнього в образі `wget`; `/health` Моніторингу відповідає `"ready": true`, без чого воркер не активував модуль (`modules/*/Dockerfile`, `modules/monitoring/monitoring_module.py`, тест `tests/test_module_images_ship_their_code.py`).
- Модулі з власною схемою БД: PostgreSQL підключається до мережі модуля під іменем `postgres` (`scripts/apply-deployment.py`); адреса БД для модуля визначається і з DSN формату `host=… port=…` (`core/module/gateway.py`).
- Bootstrap: на WSL/GPU-PV `nvidia-smi` у сховищі драйверів отримує права 0755, інакше воркер у контейнері не бачив GPU (`bootstrap.sh`).
- Web UI 3.0: публічна адреса Vertep — у «Налаштування → Загальне», спільні облікові дані платформ — на сторінці «Бренди»; вкладка «Інтеграції» їх більше не містить (`publishing.section.ts`, `v3-brands.component.ts`, `v3-settings-workspace.component.ts`); спільний контент бренду без списку не ламає сторінку (`brand-shared-content.component.ts`).
- Компонентні релізи: brands 0.0.4.17, characters 0.0.4.19, monitoring 0.0.4.17, lab 0.0.4.39, web-ui 0.0.4.38.
