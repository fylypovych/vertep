# Vertep 0.0.4.28

- Старі Docker-образи Vertep очищуються автоматично (#517): після успішного `vertep apply-update` і bootstrap `scripts/prune-images.py` записує версію та її образи (`config/installed-versions.json`) і видаляє лише образи Vertep поза трьома останніми успішними версіями, не використані жодним контейнером; `<none>` — лише з міткою джерела Vertep; `dangling=true` не використовується (containerd). Після невдалого оновлення очищення не запускається.
