# Vertep 0.0.1.93

## Task 1 — Restart consumer trigger
- Worker RESTARTING state тепер викликає `request_local_update(action='restart')` через update-agent, замість лише логування та зміни статусу.
- Шлях: CORE `desired_state=RESTARTING` → Worker heartbeat → `request_local_update` → update-agent `restart-runtime`.
- Analogous to UPDATE/ROLLBACK paths which already called `request_local_update`.

## Task 2 — Fault-injection tests
- Concurrent lease fencing: два агенти не можуть одночасно тримати UpdateLease.
- Stale lock acquisition: застарілий lock з простроченим TTL може бути примусово замінений.
- Audit hash chain tamper: підміна phase в попередньому entry виявляється при наступному append.
- Audit truncated entries: обрізаний JSON в audit log виявляється при append.
- Corrupt/empty/missing-fields status.json: recover_if_interrupted обробляє без crash.
- NORMAL status без evidence не перезаписується.
