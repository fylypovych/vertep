# Vertep 0.0.4.11

- Ролі доступу: admin і moderator (рішення власника); роль viewer прибрано, збережений viewer стає модератором без брендів. Модератор створює job, погоджує й публікує матеріали лише своїх брендів; сесія повідомляє його бренди, UI враховує бренд job.
- Налаштування → «Користувачі»: admin створює модераторів, призначає бренди, змінює роль і пароль, видаляє облікові записи (`/api/settings/users`).
- Brands → «Спільний контент» (#500): job із персонажем іншого бренду фіксує бренд-власника; публікація потребує його погодження активної версії (version + sha256), pending не публікує, revoke і зміна файлу зупиняють ще не розпочаті відправлення; рішення зберігаються з історією.
- Characters (#499): CORE перед новим job перевіряє персонажа через модуль (власник завжди, інший бренд — лише активний), недоступний модуль не пропускає job; бренд передається явно, користувач брендом не вважається; модератор змінює персонажів своїх брендів.
- Модулі (#493/#494): schema/role PostgreSQL прив'язано до module ID, колізії `a-b`/`a_b` і довгих ID відхиляються, чужі дані не перевикористовуються й не видаляються; тимчасова схема перевірки архіву поза простором `mod_`; після uninstall і відкликання вузла застарілі екземпляри втрачають READY/API/UI/dispatch.
- Monitoring (#503): історія у власній schema модуля, типово 3 дні з автоматичною ротацією, admin збільшує строк у панелі модуля; manifest і міграції узгоджено з контрактом модулів.
- Web UI (#504): панель винесено в окремий контейнер `web-ui` за proxy (`/api` → CORE, решта → панель); CORE-образ панелі більше не містить; панель показує свою збірку й попереджає про несумісний API CORE.
- Release: образи модулів (Characters, Monitoring, Brands, Storyboard, Publishing) збираються перед CORE і вшиваються в нього за sha256; CORE-образ тепер містить каталог `modules/`. Виправлено неіснуючу версію pg8000 і користувача 65532 в образах модулів.
- Bootstrap (#507): після встановлення й оновлення показується налаштований `PUBLIC_URL`/`WEB_DOMAIN`, а без нього — усі адреси хоста замість першої довільної.
- Додано наскрізний тест встановлення CORE, приєднання вузла з повтором, вибору модуля й вузла та відкликання (#496); відкликаний вузол одразу втрачає модулі.
