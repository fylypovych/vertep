# Vertep 0.0.4.63

- Безпека запуску модулів на CORE: системний виконавець не обробляє запит, якщо каталог `config/application-modules/` або `request.json` є символьним посиланням, і пише `state.json` через ексклюзивний тимчасовий файл з непередбачуваним ім'ям і правами 0600, замінюючи підкладене посилання, а не пишучи крізь нього (`scripts/apply-deployment.py`, тест `tests/test_application_modules_host.py`).
- CI: залежності модуля Storyboard (`opentimelineio` для експорту OTIO #550) встановлюються разом із тестовими (`requirements-dev.txt`) — workflow «Component releases» 0.0.4.62 упав на `ModuleNotFoundError: opentimelineio`.
- Bootstrap: NVIDIA GPU на віртуальній машині Hyper-V з GPU-P (GPU-PV) тепер виявляється — за пристроєм `/dev/dxg` і `nvidia-smi` з драйвера хоста в `/usr/lib/wsl/lib` (PCI-пристрій там Microsoft `0x1414`, а не `0x10de`); версія CUDA читається і з рядка `CUDA UMD Version`; на GPU-P bootstrap не встановлює власний драйвер через `ubuntu-drivers`, а зупиняється з поясненням. Виправлено хибне виявлення AMD: `lspci | grep 'AMD|ATI'` знаходив «ati» у «Corporation» (Microsoft, Intel) — тепер перевіряються лише відеопристрої й цілі слова (`bootstrap.sh`, тест `tests/test_bootstrap_gpu_detection.py`).
