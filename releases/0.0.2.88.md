# Vertep 0.0.2.88

Версія закриває локально виконані Issue #360–#368 і переводить CORE на новий composition root та фактичний DAG dispatch.

## Voice (#360, i.0.0.3.60)

- Каталог stock `espeak-ng` у `services/tts_service.py`: provider/model/language/voice/speed; непідтримувані комбінації відхиляються з 422, вимірювання справжнього WAV підтверджують вплив параметрів.
- `core/api/tasks.py` перевіряє issued snapshot, owner і lease до заміни файлів, реєстрації результату та ack; missing/mismatch/stale/foreign/expired result повертає 400/409 без зміни прийнятого artifact.
- Loss/lease/restart відновлюють Voice зі збереженим audio stage; cancel/stale/duplicate повертає 409, assembly дає відео з декодованим audio stream і хешем Worker contract.

## Publisher (#361, i.0.0.3.61)

- Durable publication ledger у `publishers/base.py`: fsync intent до upload, persisted receipt до CORE ack, reconciliation за runtime identity; CORE restart не скасовує живий lease.
- Невідомий результат upload зберігається як `UPLOADING`/`outcome_unknown`; сліпий повтор upload відсутній, unknown не оголошується PUBLISHED.
- Receipt (job/task/channel/version/hash) і active owner/lease перевіряються до cleanup/ack; retry використовує фактичний queue `not_before`, exhaustion обмежений, permanent/NOT_CONFIGURED не повторюються.
- Approved artifact доставляється в приватний filesystem Publisher-а з перевіркою access/version/hash/size/corruption до upload для п'яти платформ.
- OAuth у `publishers/oauth.py` зберігає encrypted credential state з expiry/refresh/scopes/revoke/reconnect; непридатні credentials блокують upload, Settings показує ready/missing scopes/error без secrets.

## CORE access (#362, i.0.0.3.62)

- Додано `tests/test_core_access_acceptance.py` і actual-backend `tests/test_core_access_browser_e2e.py` для 30 погоджених resource×role×state клітинок.
- Невідомий або пошкоджений state file більше не повертає NORMAL, використовується EMERGENCY; header не показує NORMAL до першої authoritative відповіді, recovery використовує чинну `start_recovery` policy.
- Browser перевіряє session/CSRF/logout, WAITING_FOR_SYSTEM, recovery health gate, transport faults і unknown state без `page.route`.

## Providers і MPT Settings (#363, i.0.0.3.63)

- Provider switch у `core/provider_switch.py` виконує persist→deliver→apply→verify з журналом транзакції, повторним task і restart; невдала активація повертає попередній effective config на CORE і Worker.
- Недоступний MPT не переходить мовчки в Native; snapshot і secrets не потрапляють у Job/logs, busy Worker не змінює config активного task, непідтверджене відновлення повертає 503.

## Node і Setup (#364, i.0.0.3.64)

- Enrollment після втраченої response проходить штатний retry без дублювання node identity; старий JWT відхиляється, renew/revoke працюють через API.
- Readiness і self-test семи ролей походять з actual runtime probes; Full Self-Test фіксує durable audit, stale/revoked/UNKNOWN не готові.
- Setup/Fleet Browser проходить deployment request→manifest→enrollment→reload, реальні 403/423 і retry; role matrix зараховує лише обов'язкові PG/Redis/Ollama/GPU/Docker checks.

## MPT pinned upstream (#365, i.0.0.3.65)

- Додано `docker-compose.moneyprinter.yml` з optional profile `moneyprinter`, pinned Dockerfile, Linux/amd64, окремим tasks volume, Docker secret і digest gate; оновлено `.dockerignore` та `docs/moneyprinter-runtime.md`.
- Report `scripts/issue-122-acceptance-report.py` розділяє докази `unit_or_disposable` і `pinned_runtime`.
- Фактичний pinned execution лишається BLOCKED: на host відсутні Docker Engine/BuildKit, digest і submission count не вигадувалися.

## CORE composition root (#366, i.0.0.3.66)

- `core/app.py` скорочено до 56 рядків; auth/session, SSE, Telegram, system API, lifespan і web UI mounts винесено в `core/api/auth.py`, `core/api/events.py`, `core/api/telegram.py`, `core/lifecycle.py`, `core/runtime.py`, `core/web_ui.py`.
- Прибрано `core.app` imports, `sys.modules` runtime coupling і re-export shims; відновлено `POST /api/session`, збережено dispatch table і wait helpers.
- Додано `tests/test_app_structure.py` (line budget, заборонені залежності, повний method/path snapshot, заборона top-level mutable) і `tests/test_executor_isolation.py`; snapshot маршрутів — `tests/fixtures/api-routes-before-366.json`.

## Architecture 2.0 (#367, #368)

- #367: review шести контрактів у `docs/architecture/contracts-review-367.md` з Git blob версіями та уточненнями retry/timeout/lease/module signature; пакет погоджено власником.
- #368: Workflow Engine виконує DAG через Dispatcher/Worker з parallel/retry/timeout/pause/approval/revision і persisted state у file/Redis/PostgreSQL.
- #368: module system приймає лише підписані Ed25519 packages від довіреного signer, перевіряє SemVer/dependencies/capabilities і блокує dispatch після uninstall.
- #368: версійний CORE↔Worker протокол виконує registration/assignment/claim/progress/result/renew/cancel з lease generation, одним owner і відхиленням stale result.
- #368: GPU routing використовує налаштований allowlist/priority/readiness/capacity для local_model/lab/ollama/comfyui/openai, зберігає local-only режим і показує вичерпання providers як явну помилку task.
