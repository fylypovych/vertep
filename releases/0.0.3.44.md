# Vertep 0.0.3.44

Новий майстер першого запуску, двомовна адмінпанель, коди помилок API, розподіл задач по черзі та посилення оновлень.

- Майстер першого запуску перенесено в `web-v2`; інтерфейс `/v1` і каталог `web/` прибрано (#430).
- Адмінпанель: перемикач УК/EN, збереження вибору, переклад текстів, дати за мовою (#433, #434).
- API: помилки містять машинний код, панель показує текст вибраною мовою; `detail` не змінено (#435).
- GPU: автоматичного перемикання провайдера немає, збій створює сповіщення про потребу перезапуску (#431).
- Dispatcher: пріоритети вузлів прибрано, між ідентичними вільними вузлами задачі йдуть по черзі (#432).
- Оновлення: створення job заблоковано на весь час оновлення; копія зашифрована до того, як стає ціллю відкату (#427).
- Web: на вхід веде лише 401 або відповідь без коректної identity; додано браузерні перевірки (#428).
- Publisher: готовність каналу перевіряється запитом читання до платформи; додано офіційні посилання (#429).
- Runtime bundle містить відкриті кореневі ключі й відхиляє приватні (#426).
- CI: перевірка Ubuntu чекає завершення watchdog перед запуском bootstrap.

Перевірка на реальному сервері не виконувалась.
