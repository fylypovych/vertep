# Vertep 0.0.0.95

Новий Dashboard за технічним завданням: світла мінімалістична тема, 3-колоночна структура, повний набір адміністративних дій без терміналу.

- Новий Dashboard: лівий sidebar, центральна область, правий sidebar, адаптивність до 760px.
- KPI-картки: Воркери, Активні завдання, Завдань у черзі, Навантаження системи, Використання GPU.
- Архітектура системи: CORE + групи вузлів, фільтри, навігація до Workers з prefill фільтра.
- Donut chart статусів завдань, ресурси системи, таблиця Worker з контекстним меню `⋮`.
- Детальні widgets Maintenance/Update, skeleton loading, empty/error states, warning banner.
- Profile/notification dropdowns, help button, логотип через Settings + `/api/settings/logo`.
- Розширені дії Worker: Disable, Restart, Update, View Logs через `/api/nodes/{node_id}/actions`.
- Ліцензія, recent activity, quick actions, real-time оновлення, Zero Shell принцип.
