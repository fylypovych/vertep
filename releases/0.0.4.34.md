# Vertep 0.0.4.34

- Модулі (#513): self-test відновленої версії виконується лише для модуля, що був активним або неактивним, і не повторюється після відмови в активації; відмова повертає модуль у попередній стан (`INSTALLED` або `INACTIVE`), а не `FAILED` (регресія 0.0.4.33).
- Модулі (#511): Update Manager застосовує перехід bundled-ролі в контейнерний пакет тієї самої версії через штатний план (крок `moves_into_container`); план завершується `DONE` лише після зміни виду модуля на `application`, відкат і відкладені вузли враховують цей перехід.
