# Vertep 0.0.2.57

Цей реліз закриває цикл аудитів і виправлень навколо життєвого циклу моделей, storyboard, backup та безпеки аутентифікації.

- Issue i.0.0.1.69 — Model pull lifecycle: локальний та node pull досягає COMPLETED лише за явною термінальною подією `success`; EOF без неї — це зламаний стрім, а не завершений pull; cancel закриває застряглий transport одразу, не чекаючи read timeout; пізній success/помилка не переписують термінальний стан.
- Issue i.0.0.1.62 — Storyboard results: повна валідація артефакта до мутації історії/Job; некоректний payload дає контрольовану відмову і зберігає pending/approved history, task/lease і Worker.
- Issue #160 — Backup diagnostics санітизовано (без внутрішнього URL/raw body) та наскрізний browser E2E з реальним Backup service.
- Issue #167 — OAuth scopes зберігаються з refresh-відповіді; revoke ніколи не подає порожній token.
- Issue #168/#109/#114 — безпека аутентифікації fail-closed: незаконфігурований backend доступний лише на setup-шляхах; порожні креденціали відхиляються.
- Issue #190 — секрети у publish receipts редагуються; task_id вилучається з pending лише після успішної обробки; retry з bounded backoff.
- Issue i.0.0.1.70 — heartbeat зберігає executor-observed вибір provider як доказ доставки override.
