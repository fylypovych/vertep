# Vertep 0.0.4.6

- Відновлено роботу сторінки «Персонажі» через наявний API CORE, коли модуль Characters недоступний або реєстр модулів не налаштовано.
- Уточнено маршрути, перевірку готовності профілів і перенесення даних Characters зі збереженням наявних файлів та референсів.
- Оновлено Dockerfile і залежність pg8000 для окремого контейнера Characters.
- Оновлено перевірки Characters та Browser E2E для сторінки «Модулі» і роботи з персонажами.
