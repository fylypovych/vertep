- CI 0.0.3.67: CORE стартує поряд зі старшим пакетом `worker` (лінивий імпорт `voice_catalog`); `vertep remove` відхиляє системний root за префіксом до звернення до файлової системи, без `PermissionError`; Browser-тести оновлено під UI #450/#456.

- Відеодвижки (#462): рішення власника видалити ShortGPT замість локальної інтеграції записано в `docs/acceptance/video-engines-456.md`.
