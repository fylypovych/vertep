# Vertep 0.0.3.5

## B2 — Executor trust boundary: unsafe archive / symlink / cross-origin

Додано 6 нових тестів у `tests/test_update_security.py` що закривають відсутні виміри матриці executor trust boundary:

- `test_safe_extract_rejects_symlink_member` — symlink attack
- `test_safe_extract_rejects_path_traversal_member` — path traversal
- `test_safe_extract_rejects_absolute_path_member` — absolute path injection
- `test_safe_extract_rejects_cross_origin_hardlink` — cross-origin hardlink
- `test_safe_extract_rejects_size_bomb` — tar bomb / size limit
- `test_safe_extract_accepts_legitimate_archive` — happy path

## B3 — Failure→rollback маршрут bootstrap

`scripts/qualify_ubuntu_bootstrap.py` тепер містить `simulate_bootstrap_failure_and_rollback()`:
- записує стан до failure (HTTPS, credentials, certificate)
- викликає `vertep rollback` (той самий бінарний файл що `rollback_after_failure()` у bootstrap.sh)
- перевіряє що система залишається healthy після rollback
- перевіряє що credentials та certificate не змінились

## B4 — Criterion-level report

`scripts/qualify_bootstrap_lifecycle.py` тепер генерує `b4_report` JSON із:
- `EXECUTOR_TRUST_DIMENSIONS` — авторитативний список test IDs per dimension
- `b4_dimension_report()` — per-dimension статус PASS/PARTIAL/NOT_RUN
- observed executor architecture, harness SHA, installed runtime info
- dimensions: tamper, expiry, revoke, channel, downgrade, rotation, recovery, unsafe_archive, symlink, cross_origin, compatibility
