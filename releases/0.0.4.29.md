# Vertep 0.0.4.29

- Бічне меню панелі (#518): «Дашборд» першим над групою «Контент»; «Контент»: Завдання → Черга виконання → Опубліковане → Персонажі → Бренди → Шаблони обробки; «Система»: Стан системи → Алерти → Логи → Стан підключень → Вузли → Модулі → Оновлення → Бекапи → Реальні тести; вкладки налаштувань — у тому ж відносному порядку. Заголовок сторінки тепер оновлюється під час переходу з меню (раніше лишався заголовок попередньої сторінки).
- Update Manager (#512): погоджена версія плану передається агенту оновлення, і він встановлює саме цей реліз (`releases/tags/<версія>`), а не `latest`.
- Відновлення оновлення модуля (#513): після відновлення записи лишаються заблокованими до перевіреного кінцевого стану; намір і ліміт повтору зберігаються в журналі до повтору — обрив між відновленням і повтором не дає другої спроби.
- Відкат модуля з панелі (#515) виконує Update Manager як окрему операцію з власними записами журналу UPDATE; панель показує журнал відкату; блокування Update Manager спільне на всю установку.
