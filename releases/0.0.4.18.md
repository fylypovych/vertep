# Vertep 0.0.4.18

- Модулі працюють у типовому статичному режимі workflow: реєстр, lifecycle, каталог «Модулі», «Вузли», Gateway модулів, Brands і звіти Worker про модулі використовують окремий модульний runtime, незалежний від динамічних шаблонів workflow. Раніше на стандартній установці сторінка «Модулі» показувала «Шаблони workflow не налаштовано». Задачі модулів на спільних можливостях Worker у статичному режимі отримують зрозумілу відмову 409.
- Служба розгортання на хості (`vertep-deployment.service`) більше не падає: runtime bundle містить модуль `adapters/comfyui_runtime.py`, який імпортує `apply-deployment.py`. Новий тест збирає підписаний bundle і запускає всі хост-скрипти системним Python без репозиторію.
- Сторінка «Модулі» має власний заголовок.
