# Vertep 0.0.3.100

## Виправлення Angular build (web-v2) та тестів CI

### Web UI (web-v2) — Angular build fixes
- **Character interfaces** (`web-v2/src/app/core/models/domain.ts`): додано `owner_brand_id?: string` та `active?: boolean` в інтерфейси `Character` та `CharacterForm` — відповідає модулю characters (#499).
- **ResourcesApiService** (`web-v2/src/app/core/api/resources.api.ts`): додано метод `moduleCharacterCollaborations(id)` для отримання списку співпраць персонажа.
- **CharactersComponent** (`web-v2/src/app/characters/characters.component.ts`):
  - Виправлено виклики API: `moduleAddCollaboration(id, brandId)` та `moduleRemoveCollaboration(id, brandId)` замість неіснуючих `moduleAddCharacterCollaboration`/`moduleRemoveCharacterCollaboration`.
  - Payload для `moduleCreateCharacter`/`moduleUpdateCharacter` включає обов'язкові для `ModuleCharacter` поля: `references: []`, `collaborations: []`, `is_owner: true`.
  - Видалено невикористовуване поле `newCollabPermission` (API персонажів не підтримує рівні дозволів для співпраці — лише `brand_id`).
  - Шаблони оновлено: `removeCollaboration` приймає `brand_id` з об'єкта співпраці.

### Assembly pipeline (#498) — правильний job flow у тестах
- Додано helper `_complete_assembly_task()` у `tests/test_api.py` для імітації Worker-а з capability `video_assembly`.
- Оновлено 4 падаючих тести для коректного проходження через новий статус `ASSEMBLY`:
  - `test_health_and_job_flow`
  - `test_regenerate_preserves_inputs_and_replaces_generated_artifacts`
  - `test_job_export_import_and_optimistic_lock`
  - `test_distributed_worker_result` — реєструє GPU worker з capabilities `image_generation`, `video_generation`, `video_assembly`
- Це відображає архітектурну зміну #498: весь фінальний монтаж виконується Worker-ом; CORE лише формує незмінну спробу, ставить в чергу і верифікує/імпортує результат.

### API routes snapshot
- Виправлено `test_all_method_path_contracts_match_the_before_extraction_snapshot` у `tests/test_app_structure.py`: додано відсутній маршрут `GET /api/nodes/module-catalog` (Issue #496) до списку очікуваних execution routes.

### Результат
Усі локальні перевірки проходять (compileall, diff --check). Angular build у web-v2 має зібратися без помилок. CI тести мають коректно перевіряти повний job flow через ASSEMBLY статус.
