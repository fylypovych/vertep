# Vertep 0.0.1.55

## Відео-апробація

Після збірки відео завдання переводиться у стан `VIDEO_PENDING_APPROVAL` замість прямого переходу до `READY`. Це дозволяє оператору оглянути отриману відео-збірку та за потреби запросити правки або схвалити для публікації.

### API

- `POST /api/jobs/{job_id}/video/approve` — схвалити відео, перехід до `READY`.
- `POST /api/jobs/{job_id}/video/revision` — запросити правки до відео.
- `POST /api/jobs/{job_id}/video/regenerate` — перегенерувати відео з поточними кадрами.
- `POST /api/jobs/{job_id}/publish` — явно блокує публікацію, доки відео не затверджено.

### Web UI

У розділі деталей завдання тепер відображається video-превʼю разом із кнопками «Схвалити відео», «Правки до відео» та «Регенерувати відео» у відповідних станах.

### Telegram

Опція залишена без змін — клавіатура `vid_ok` / `vid_edit` / `vid_regen` / `vid_reject` працює з новими endpoint-ами.

## Виправлення

- Прибрано dead code у `_prepare_and_dispatch`.
- Додано `VIDEO_READY → {READY, CANCELLED}` у `JOB_STATE_TRANSITIONS`.

## Межі реалізації

Наявність endpoint і переходу ASSEMBLY не означає завершеного regeneration: dispatch, застосування правок, збереження попередніх video versions та restart-safe approval залишаються в Issue #49. Повний acceptance цієї функції не оголошується виконаним.
