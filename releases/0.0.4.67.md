# Vertep 0.0.4.67

- Безпека LAB (#491): для закріпленого самопідписаного сертифіката CORE перевірка імені хоста більше не вимикається — ім'я звіряється з тим, що записане в самому сертифікаті (`lab/tls.py`, тести `tests/test_lab_tls_pinned_core.py`).
- Безпека БД модулів: PostgreSQL приєднується до мережі модуля лише після того, як `pg_hba.conf` дозволяє з підмережі модуля вхід тільки його власній ролі й відхиляє всі інші, включно з власником CORE; невалідні правила відкочуються, і PostgreSQL до мережі не приєднується (`scripts/apply-deployment.py`, тести `tests/test_application_modules_host.py`).
- Web UI (#554): спільний стан навігації `NavigationStateService` — меню модулів, «Бекапи» й «Лабораторія» оновлюються одразу після активації/деактивації модуля чи підключення LAB, без очікування 30-секундного опитування (`sidebar.component.ts`, `v3-sidebar.component.ts`, `module-management.component.ts`, `system-info.section.ts`).
- Web UI 3.0: підсвічування пунктів меню для сторінок-псевдонімів (черга, здоров'я, алерти, журнали, workflows); заголовок сторінки модуля в шапці; модератор бачить «Шаблони обробки» без адміністративних вкладок конвеєра; посилання `tab=publishing` веде до облікових даних платформ у «Брендах», а без модуля Brands — до «Інтеграцій» (`v3-navbar.component.ts`, `v3-pipeline-workspace.component.ts`, `v3-settings-workspace.component.ts`, `ui-version.service.ts`, `v3.routes.ts`, E2E `web-v2/tests/issue-536-web-v3.spec.ts`).
- Експорт сторіборду (#550): для активної версії зображення, відео й аудіо сцен беруться з артефактів фактичних сцен виконання (`scene-NNN`), а не лише з полів сторіборду — у production-конвеєрі експорт був порожнім (`core/module/gateway.py`, тест `tests/test_storyboard_otio_550.py`).
- Реліз: образи `stt`, `lora-trainer`, `musetalk` збираються release workflow, потрапляють у manifest і підставляються bootstrap/оновленням з закріпленим digest (`.github/workflows/release.yml`, `bootstrap.sh`, `scripts/update-runtime-env.py`, `scripts/qualify-release.py`; також `moneyprinter` в оновленні середовища).
- LAB (#546): контейнер керування працює від непривілейованого користувача `10001`; оцінювання моделей у bubblewrap використовує `--unshare-user-try`, для чого контейнерам LAB вимкнено профілі seccomp/AppArmor при `cap_drop: ALL` і `no-new-privileges` (`deploy/lab/Dockerfile`, `deploy/lab/docker-compose*.yml`, `lab/eval_network.py`).
- Документація: матриця «Контракт → Код → Тест» для Character Knowledge & Memory K0 (`docs/character-knowledge-k0-matrix.md`).
- Компонентні релізи: web-ui 0.0.4.39, lab 0.0.4.40.
