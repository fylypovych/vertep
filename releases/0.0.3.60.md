# Vertep 0.0.3.60

- Виправлено acceptance-тести Browser E2E #354: локалізований Health Check, OPTIONAL для невибраної Ollama, ізоляція локальних і віддалених ролей стенда та очікування `script_task_id` перед запитом задачі.
- Усунуто контрактні падіння CI #435: новий route майстра, машинні коди API-помилок із перекладом і перевірка читабельного підсумку інсталяції.
- Bootstrap зупиняє автоматичні triggers до перевірки активних executor-ів і лише після перевірки можливостей середовища.
- Host units і health endpoint вибираються за контрактом конкретного signed runtime. Старі опубліковані релізи не вимагають нових observer-артефактів; новий runtime з неповним observer-контрактом відхиляється без переходу на legacy liveness.
- Додано тести сумісності bootstrap зі старим, новим і неповним runtime. Перевірки підписів і контрольних сум збережено.

- Інсталятори підтримують Ubuntu Server 24.04 та 26.04: окремі package pins Docker/Compose, тести вибору платформи та захист від встановлення Noble ROCm на 26.04.
