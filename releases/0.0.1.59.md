# Vertep 0.0.1.59

Робота над структурованою часовою лінією job та серверною пагінацією списку job у Web UI V2.

- Додано структуроване сховище подій job (`JobEvent`, `Job.event_log`): події фіксуються з реальним timestamp і полями state/attempt/node/task_id/artifact_id/error; legacy список `events` збережено.
- `GET /api/jobs` розширено серверними фільтрами та пагінацією (`status`, `status_group`, `search`, `page`/`per_page`) з групами статусів `STATUS_GROUPS`; без параметрів повертається legacy масив.
- Додано endpoint `GET /api/jobs/{job_id}/events` для структурованої часової лінії job.
- Web UI V2: список job переведено на серверну пагінацію/фільтрацію; job-detail показує версії конфлікту та кнопку «Застосувати зміни знову», таймлайн рендериться зі структурованої `event_log`.
- Додано backend contract тести `tests/test_job_workspace_contracts.py`; оновлено Playwright-тести jobs.
