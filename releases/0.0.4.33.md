# Vertep 0.0.4.33

- Модулі: воркер на CORE повідомляє вбудовані модулі не лише ролі `NODE_ROLE`, а й додаткових ролей (`NODE_ADDITIONAL_ROLES`: backup, text тощо); раніше активація такого модуля (Backup) на основному вузлі падала з «Module self-test failed», бо вузол не повідомляв модуль.
- Модулі (#513): після невдалого оновлення неактивного модуля відновлена версія теж проходить self-test; якщо перевірка не пройшла, модуль переходить у `FAILED`, а блокування записів лишається.
- Компонентні релізи (#510): маніфест компонента бере сумісність CORE/API з маніфесту пакета контейнера (`package_manifest`); для Publisher `compatibility.core` і `compatibility.api` більше не порожні.
- Модулі (#511): bundled-роль Publisher переходить у контейнерний пакет тієї самої версії через офіційне джерело — оновлення пропонується й застосовується; повторно та сама версія не пропонується.
