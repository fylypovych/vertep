# Vertep 0.0.3.31

- Референси персонажа: у редакторі можна прикріпити до 5 зображень PNG, JPEG або WebP; вони автоматично застосовуються в генерації зображень цього персонажа. Вузол отримує файли з CORE і перевіряє контрольну суму.
- ComfyUI: шаблон `workflows/image/ip-adapter.json`, розширення ComfyUI_IPAdapter_plus із закріпленою версією в образах NVIDIA й AMD. Шаблон без входу `{{REFERENCE_IMAGE}}` завершує генерацію з референсами помилкою. Моделі IP-Adapter додаються на сервер окремо; реальна генерація не перевірялась.
- Тести: браузерний тест майстра враховує крок Telegram; тест запиту оновлення очікує фактичну версію.
