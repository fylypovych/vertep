# Vertep 0.0.4.60

- Publisher (#538): перевірка `configured()` у `publishers/runner.py` виконується з per-task секретами CORE (`use_task_secrets`), тож віддалена Publisher Node без `DATABASE_URL` і env-токенів більше не повертає хибне `NOT_CONFIGURED`; TikTok (`publishers/tiktok/__init__.py`) опитує `status/fetch/` до фінального статусу — `FAILED` не позначається як `PUBLISHED`, а перевищення таймауту фіксується як невідомий результат без повторного завантаження; `POST /api/jobs/{job_id}/publish` не ставить повторно в чергу канали, вже опубліковані для активної версії відео (`core/api/jobs.py`).
- GPU/Dispatcher (#538): `image_storyboard_result` перевіряє власника й активний lease і повертає `409` при невідповідності (`core/api/task_results.py`, код помилки в `core/api_error_codes.json` та переклад у `web-v2/src/app/core/i18n/api-errors.ts`); воркер звітує `vram_mb`/`free_vram_mb` найбільшої окремої GPU замість суми і передає список `gpus` (`worker/service.py`); перевірка outbound-only розбирає Compose як YAML — inline, багаторядковий блок `ports:` і long-syntax `published:` (`core/outbound_only.py`); очищення тимчасових файлів прибирає застарілі `*.part`/`*.part.<ext>`, не чіпаючи свіжих і нумерованих частин бекапу (`core/maintenance.py`).
- ComfyUI AMD (#538): `docker/comfyui-amd/Dockerfile` вирівняно з NVIDIA — закріплені commit ComfyUI, `ComfyUI-VideoHelperSuite` і `ComfyUI_IPAdapter_plus` з перевіркою pin, усі три в `runtime-inventory.json` і спільний `entrypoint.sh`, що публікує звіт у `/data/runtime-report`.
- TTS (#538): `PiperProvider` використовує стандартний HTTP API Piper — `POST /` з JSON (`speaker_id`/`speaker`) замість `GET /synthesize` (`adapters/providers/tts_backends.py`).
- Release workflow: перевірка кількості закріплених образів модулів відповідає матриці (4), тест звіряє її з кількістю модулів у матриці (`.github/workflows/release.yml`, `tests/test_release_module_images.py`).
