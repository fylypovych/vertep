# Vertep 0.0.1.33

Реалізовано Issue #16: завершено Backup/Restore та Backup Node. Реальний backup-сервіс із AES-256-GCM шифруванням, retention policy, remote storage hooks, кастомними inventory джерелами, restore progress, system-state gating та post-restore health verification.

Зміни:
- `services/backup_service.py`: повний inventory (config/storage + опціональні pg_dump/redis_dump), retention за часом та кількістю, remote copy, system-state гейти, прогрес restore, health verification.
- `core/app.py`: `/api/system/state` для стану системи, проксі `/api/system/backups/{snapshot_id}/restore/progress`.
- `core/api/system.py`: оновлено для узгодженості.
- `.env.example`: додано `BACKUP_SOURCES`, `BACKUP_RETENTION_DAYS`, `BACKUP_MAX_SNAPSHOTS`, `BACKUP_REMOTE_CMD`, `BACKUP_CORE_URL`, `BACKUP_PG_DUMP_CMD`, `BACKUP_REDIS_DUMP_CMD`.
- Web UI V2: розширено `SettingsComponent` — inventory, прогрес restore, system-state warning, disable кнопок, polling прогресу; оновлено `BackupInfo` та API service.
- `scripts/restore.sh`: гейти за станом, `.vtbackup` підтримка, post-restore health check.
- Тести: 4 нові тести в `tests/test_role_services.py` (retention, emergency block, restore progress, custom sources); усі 312 тестів проходять.
