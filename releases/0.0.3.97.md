# Vertep 0.0.3.97

## Web UI Application Module (#504)

Реалізовано повний Web UI Application Module — уніфікований веб-інтерфейс Vertep, що об'єднує всі модулі в єдиний дашборд.

### Основні можливості

- **Модуль `modules/web-ui/`**: manifest schema 2.0, kind=application, namespace `web-ui`, UI entry `index.html`
- **Залежності**: `characters`, `brands`, `storyboard`, `publishing`, `monitoring` — доступ до даних усіх модулів
- **Уніфікований UI**: адаптивний сайдбар навігації, дашборд статистики, вкладки для кожного модуля
- **Інтеграція модулів**: iframe embedding для Characters, Brands, Storyboard, Publishing, Monitoring
- **Управління темами**: створення/редагування/видалення тем, тема за замовчуванням
- **Конфігурація UI**: ключ-значення конфігурація для налаштувань інтерфейсу
- **Навігація**: динамічне меню з правами доступу, порядком, іконками
- **Інформація про модулі**: список доступних модулів зі статусом enabled/disabled

### API (Application Module)

- `GET/POST /api/modules/web-ui/v1/config` — конфігурація UI
- `GET/POST/PUT/DELETE /api/modules/web-ui/v1/themes` — теми
- `GET /api/modules/web-ui/v1/themes/default` — тема за замовчуванням
- `GET/POST/PUT/DELETE /api/modules/web-ui/v1/navigation` — навігація
- `GET /api/modules/web-ui/v1/modules` — інформація про модулі
- `POST /api/modules/web-ui/v1/migrate` — міграція legacy даних

### База даних

Таблиці: `ui_config`, `ui_themes`, `ui_navigation`
Схема: `web_ui`, міграції в `migrations/`

### Capabilities

`web_ui` — веб-інтерфейс та управління UI

### CORE інтеграція

- Додано `"web-ui"` у `BUNDLED` в `core/module/lifecycle.py`
- Додано `"web-ui": "Web UI"` у `BUNDLED_LABELS` в `core/module/catalog.py`

### Головний інтерфейс

`modules/web-ui/ui/index.html`:
- Адаптивний боковий сайдбар з навігацією
- Дашборд: статистика вузлів, алертів, персонажів, публікацій
- Швидкі дії: новий персонаж, бренд, скрипт, публікація
