# Vertep 0.0.1.52

## Завершено RBAC UX (Issue #29, `i.0.0.0.27`)

- Profile dropdown у header замість аватара як прямої logout-кнопки: окремі дії «Профіль», «Змінити пароль», «Вийти».
- Profile page: логін, роль, перелік дозволених дій, форма зміни пароля — все через Web UI без shell.
- Route-level authorization: `AdminGuard` для `/settings`, sidebar приховує admin-пункти для viewer.
- System-state guards (`MAINTENANCE`, `UPDATING`, `EMERGENCY`, `RECOVERING`, `READ_ONLY`) узгоджені backend+frontend через `PolicyService`; заблокована дія пояснює причину.
- Backend RBAC: viewer отримує 403 на будь-яку admin mutation (прямим API також); CSRF обовʼязковий.
- Self-service `/api/session*` дозволено для viewer; зміна пароля підтримує будь-якого авторизованого користувача через persistent user store.
