# Vertep 0.0.2.35

- Виправлено Settings → Движок відео: повторне читання конфігурації після застосування більше не затирає адресу runtime, яку оператор встиг змінити поки запит був у польоті — форма більше не повертається мимо введеного значення (`choose()` порівнює адресу на момент запиту).
- Browser E2E `test_settings_video_engine_repoints_the_runtime_of_the_current_engine` тепер очікує завершення повторного читання конфігурації перед наступною зміною адреси, тому перевірка «повернення попередньої адреси знову робить Apply доступним» більше не залежить від порядку відповідей.
