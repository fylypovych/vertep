# Vertep 0.0.4.25

- Локальний воркер CORE-сервера ходить до proxy всередині мережі Docker (`https://proxy:8443`) і довіряє лише закріпленому сертифікату CORE: на стенді з 0.0.4.23 публічна адреса з `WEB_DOMAIN` була недоступна з контейнера, і воркер перезапускався з «Connection refused». Пропозиція реєстрації з 0.0.4.23 замінюється одразу.
