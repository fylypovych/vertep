# Vertep 0.0.3.33

- Lab: встановлення однією командою `bootstrap-lab.sh` на окремій Ubuntu 24.04 VM; панель доступна лише локально, спільний GPU вимкнено.
- Спільний GPU: у CORE додано `/lab-lease/v1` для видачі, відкликання й звільнення дозволу; за замовчуванням вимкнено, завдання Vertep мають пріоритет.
- Lab викликає модель через `/lab-lease/v1/inference` лише з чинним дозволом; відкликання перериває виклик, а при звільненні модель прибирається з пам'яті.
- Lab: додано `lab/role_service.py` для завдань аудиту, перевірки та звіту й підтримку власного сертифіката Vertep.
- На реальній VM і GPU не перевірено.
