# Vertep 0.0.3.50

- Перевірка Telegram-каналу: готовність вимагає заданий канал і право бота публікувати в ньому; причину видно оператору.

- Тести: одночасні запити задач, порядок після перезавантаження сховища CORE, справжнє завантаження файла копії в браузері, успіх оновлення лише за робочих CORE, PostgreSQL і Redis.
