# Vertep 0.0.2.42

## Issue #122 P0-P12 — MoneyPrinterTurbo інтеграція як opt-in VideoEngine (Native за замовчуванням)

### Architecture
- `adapters/providers/video_engines.py`: Реалізовано `NativeVertepEngine` (за замовчуванням), `MoneyPrinterEngine`, `ShortGPTEngine` — усі через інтерфейс `VideoEngine`. Вибір двигуна зберігається, виживає перезавантаження, Worker повідомляє ефективний двигун.
- `adapters/providers/runtime_manifest.py`, `scripts/moneyprinter-runtime-check.py`: P2 — pinned runtime верифікація: інвентар із dependency digests, SBOM, image digest, bridge/API version constants. Gateway відмовляє при drift.
- `services/moneyprinter_service.py`: Wrapper навколо pinned MPT runtime (§9.2) з gate `/health`, `/runtime`, `/self-test`; upstream лише loopback, обов'язковий непустий `x-api-key`, voice staging через content-addressed marker ДО upstream POST (P3 race mitigation), durable submit key з reconciliation (P6), fenced abort при помилці staging.
- `core/api/job_helpers.py`, `core/pipeline.py`: Dispatch assembly задачі через Worker; engine/config snapshot у Job/attempt; approved inputs доставляються Worker з ownership/checksum; Publisher залишається єдиною publication boundary.

### Tests
- `tests/test_video_engines.py`, `tests/test_moneyprinter_runtime.py`, `tests/test_assembly_worker_route.py`: Повна матриця тестів для contract, media, integration, recovery, security, configuration, delivery (§6); 387 тестів проходять.
- `scripts/issue-122-acceptance-report.py`, `scripts/issue-122-retirement-trace.py`: P10 — трасуваний §6 acceptance report (JSON+MD) і P12 — retirement trace (117 рядків, 0 retire, 0 blocked).
