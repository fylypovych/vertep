# Vertep 0.0.3.66

- Відновлено ознаку виконуваного файла (100755) для `bootstrap.sh`, `install.sh`, `scripts/vertep`, `installer/detect-gpu.sh`, `installer/install-comfyui.sh`, `installer/preflight.sh` та `installer/roles/*.sh`, знятої в 0.0.3.65; вміст файлів не змінювався.
- Причина: GitHub Desktop у Windows працював із клоном у файловій системі WSL з `core.filemode=true` і показував права як зміни. Для цього клону встановлено `core.filemode=false`; права файлів у Git задаються явно.
