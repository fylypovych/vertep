# Vertep 0.0.3.67

- Реальні тести (#451): каталог сценаріїв позначено як локальний; `IR_COVERAGE` зіставляє всі відкриті real-server Issues з покриттям сценаріями. Auto-close закриває Issue лише за повного покриття, тож часткові сценарії результат публікують, але широкий `ir` не закривають. UI показує критерії сценарію та Issues без сценаріїв.
- Security (#452): Browser-перевірка геометрії SHA-256 у картці сертифікатів на ширинах 1440/900/375/640 px без накладання на «Інтеграції».
- Налаштування (#453): облікові дані соцмереж перенесено до «Публікації» з групуванням за платформою; «Ключі інтеграцій» містять ключі сервісів Vertep. Токен Telegram-бота один для керування й публікації в канал і змінюється в одному місці.
- Ollama (#454): каталог моделей для завантаження (`core/ollama_catalog.json`, теги й розміри звірено з реєстром Ollama, `scripts/verify-ollama-catalog.py`); перевірка назви, окремі причини помилок, повтор саме завантаження; встановлені моделі показано окремо від каталогу.
- TTS (#455): голоси з читабельними назвами замість `[object Object]`; `default` — голос рушія за замовчуванням, тож проходить і self-test ролі Voice; швидкість у словах за хвилину з межами runtime; причина помилки прослуховування читається з аудіо-відповіді.
- Відеодвижки (#456): ShortGPT видалено; збережений вибір `shortgpt` відхиляється без переходу на Native. Локальний MoneyPrinterTurbo вмикається з UI без адреси й токена: runtime і локальний Worker зі складанням додаються до плану розгортання штатним executor. Готовність Native перевіряє FFmpeg у CORE; UI розрізняє чернетку й застосований движок.
