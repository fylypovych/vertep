# Vertep 0.0.3.61

- Розділено готовність CORE для керування та повну готовність вибраних ролей: несправна GPU-служба не блокує доступ до початкового майстра й адміністративного відновлення.
- Bootstrap першої інсталяції використовує control health gate для сумісного signed runtime; оновлення налаштованих інсталяцій і старі runtime зберігають повну перевірку ролей.
- У майстрі додано явний вибір додаткових ролей CORE та можливість прибрати недоступну роль до завершення налаштування; додано API, shell і Browser перевірки.
