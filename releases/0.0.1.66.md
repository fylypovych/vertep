# Vertep 0.0.1.66

## Мета
Закриття залишкового реліз-блокуючого дефекту: доопрацювання signing-flow генерації root metadata та приведення `test_key_lifecycle.py` до узгодженого ланцюга.

## Зміни
- `scripts/generate-root-metadata.py`: `build_metadata` підписує метадані приватним ключем і записує в `release_keys[].sha256` дайджест публічного ключа (`_public_sha256`). Метадані тепер сумісні з `core/update_trust` (validate/authorize за публічним keyring).
- `tests/test_key_lifecycle.py`: переписано під робочу модель — приватний signing store (`generate-root-metadata.generate_key`) + публічний verification keyring (`core/update_trust`). Ці тести потребують openssl, тому скипаються на Windows; на Linux CI вони тепер проходять.

## Перевірка
- `python -m compileall -q scripts/generate-root-metadata.py tests/test_key_lifecycle.py`: OK.
- `pytest --collect-only tests/test_key_lifecycle.py`: 4 tests collected.
- Повна верифікація openssl-тестів виконується на Linux CI у `prepare`-вороті release workflow.
- `git diff --check`: без проблем.
