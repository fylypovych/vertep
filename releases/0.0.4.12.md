# Vertep 0.0.4.12

- Роль viewer видалено повністю: лишилися admin і moderator; невідома збережена роль діє як модератор без брендів. UI отримує бренди модератора із сесії; модератор без брендів не створює job. Browser E2E використовує акаунт модератора.
- Бренди (#500, рішення власника): модуль Brands став єдиним власником брендів, каналів (канал↔бренди M:N без копій підключення) і політик публікації (бренд і перевизначення каналу). CORE працює з ними через модуль (`core/brand_store.py`) і не повертається тихо до старих даних; `POST /api/brands/migrate-to-module` переносить наявні бренди й канали зі збереженням ID. Модератор змінює лише свої бренди.
- «Спільний контент» (#500): погодження всіх брендів-власників персонажів; зміна персонажа в job перевіряється модулем і додає власника; бренд-власник створює власну незалежну публікацію того самого артефакту зі своїми текстами; revoke і зміна джерела зупиняють ще не розпочаті відправлення; перевірено конкурентний revoke/старт відправлення.
- Characters (#499): наскрізний тест на тимчасовому PostgreSQL — встановлення й активація пакета з власною schema, API і UI, міграція legacy-персонажів з явним власником, деактивація при запущеному й погоджуваному матеріалі, архів і відновлення з read-back ID, власників, референсів та історії.
- Встановлення (#496): Browser-тест першого встановлення з вибором модуля у Wizard, токена приєднання у «Вузлах», enrollment з повтором, розміщення й активації модуля у «Модулях» та заборони для модератора.
- LAB (#493 AC6): кожен виклик LAB до CORE (`/lab-lease/v1/…`), включно з probes і відмовами, записується в audit trail платформи.
- Bootstrap (#507): адреса UI перевіряється суворо — `PUBLIC_URL` з неіснуючим IP, query/fragment, обліковими даними чи недопустимим портом ігнорується, некоректні IPv6/IPv4 кандидати не друкуються; шлях Wizard (`/setup?token=…`) складається коректно й для `PUBLIC_URL` з підшляхом.
- Web UI (#504): відкат панелі на попередній образ зберігає активну сесію (cookie належить CORE), CORE і його фонова робота не перезапускаються; панель показує свою збірку після оновлення та відкату (стан версії в сайдбарі — signals). Додано контейнерний тест оновлення→відкату з перевіркою digest образу та некешованого shell.
