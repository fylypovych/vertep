# Vertep 0.0.1.20

## Jobs — перегляд та редагування

Створено новий компонент Job Detail (`/jobs/:id`) з повним переглядом завдання:
- ID, тема, статус, пріоритет, дата створення/оновлення
- Персонаж, workflow, task type, aspect ratio, output preset
- Робочий вузол, публікації, scenes, artifacts, історія подій

Додано кнопку "Редагувати" для зміни теми, пріоритету та workflow. Додано кнопку "Видалити" з confirm-діалогом.

## Dashboard — статуси завдань

Виправлено підрахунок статусів: тепер рахує з реальних jobs з `/api/jobs`:
- В процесі, Очікують, Завершено, Помилки, Призупинено, Скасовано, Очікують систему

Маппінг статусів винесено в константу `JOB_STATUS_GROUPS` для централізованого керування.

## Dashboard — архітектура системи

Покращено блок "Архітектура системи":
- Показує CORE + встановлені модулі (LLM, TTS, GPU, FFmpeg, Telegram)
- Worker nodes з ролями та capabilities
- Дані будуються з фактичних відповідей backend

## Dashboard — ресурси системи

Додано реальні метрики CPU, RAM, Disk через `psutil`:
- `/api/status` тепер повертає `resources: {cpu, ram, disk}`
- Dashboard показує progress bars або "Недоступно" замість фальшивого 0%

## Settings — Система

Замість raw JSON тепер user-friendly таблиця:
- Стан системи, версія, ядро, PostgreSQL, Redis, сховище, Telegram
- Черга, активні завдання
- Кнопка "Показати технічні деталі" для advanced view

## Дати

Створено `VertepDatePipe` — єдиний формат `дд.мм.рррр год:хв` для всього Web UI V2.

## Тести

Додано 8 нових browser E2E тестів:
- `test_job_detail_view_and_edit` — відкриття та редагування Job
- `test_jobs_delete_button_is_present` — наявність кнопки видалення
- `test_dashboard_job_status_counts` — правильний підрахунок статусів
- `test_settings_shows_user_friendly_system_info` — user-friendly System block
- `test_settings_shows_resources_or_unavailable` — ресурси або "Недоступно"
- `test_settings_update_shows_correct_version` — синхронізація версії
- `test_dashboard_architecture_shows_core_and_workers` — архітектура з workers
- Оновлено існуючі тести для нової функціональності
