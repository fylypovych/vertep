# Vertep 0.0.1.73

## Відео: immutable-версіювання та ревізія

Додано иммутабельне версіонування фінального відео. Кожен рендер зберігається окремим файлом `final/video-v<N>.mp4` із записом `VideoVersion` (sha256, approved, approved_by, revision_note). Legacy-вказівник `final/video.mp4` створюється як backward-compat symlink або копія. Відновлення після рестарту розрізняє схвалену версію (перехід до READY) та несхвалену (VIDEO_PENDING_APPROVAL). Ревізія відео зберігається як `VideoRevision`, прив'язаний до конкретної версії, і підтримує перехід як у `VIDEO_GENERATION`, так і в `ASSEMBLY`. Telegram-колбеки затвердження прив'язані до версії (`job_id:version`), захищаючи від stale-approval; додано захист від подвійної регенерації (`video_regenerating`).

## Сценарій: ревізія script через revision

Ревізія script зберігається в полі `revision` Job і передається в script-задачу та LLM-промпт як `REVISION INSTRUCTION`. Стан `SCRIPT_QUEUED` розділяє чергування та призначення задачі; дефолт `LOCAL_WORKER_FALLBACK` змінено з `true` на `false`.

## Dispatcher: runtime readiness

Worker зберігає `runtime_status` (ONLINE / PENDING_SELF_TEST) після self-test; dispatcher використовує лише підтверджені `tested_capabilities` (без fallback до declared) і виключає вузли з непройденим runtime self-test з dispatch.

## Publisher: permanent vs transient помилки

`NOT_CONFIGURED` повертає receipt без retry; транзиентні помилки (network, timeout, rate limit) викликають exception для retry воркером; додано `publish_retry_count` та `published_channels`.

## Real Test Runner

Новий пакет `core/real_tests/` реалізує повний цикл реальних тестів: start → run_checks → finalize → report_to_github → close_issue. API `/api/real-tests/scenarios|run|runs`. Звітування в GitHub Issues — ідемпотентне, з retry і REPORT_PENDING fallback. Сценарії містять `rt_issue` з прив'язкою до GitHub ir Issue.

## Release gate

Новий `scripts/check-release-gate.py` та крок `release-gate` у `.github/workflows/release.yml`: перевірка, що CI та Browser E2E workflow мають успішний completed run для точного SHA перед збіркою images та публікацією Release.

## Web UI
