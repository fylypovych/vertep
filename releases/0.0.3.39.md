# Vertep 0.0.3.39

Виконання #414–#416, доповнення #404, #405, #411–#413.

- Publisher: заглушки `publisher_service` прибрано; self-test перевіряє готовність каналів через CORE без публікації та без передачі секретів; вузол без налаштованого каналу не вважається готовим.
- Оновлення: оновлення на CORE приймається лише після відповіді CORE, PostgreSQL і Redis; Worker із несумісним контрактом не отримує задач.
- Копії перед оновленням: шифрування, окремий ключ `.update-backup.key`, очищення старих копій; пароль Redis не передається в командному рядку.
- Threads: адреса API `graph.threads.com`; статус контейнера опитується раз на хвилину; Facebook не робить зайвого запиту посилання.
- Тести: цикл Worker цілком, справжні `pg_dump`/`pg_restore` і стан запуску на PostgreSQL; `local-contracts` у CI виконується паралельно.

Локальні тести й CI для цієї версії не запускались, перевірка на реальному сервері не виконувалась.
