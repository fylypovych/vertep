# Vertep 0.0.3.99

## Виправлення тестів CI (unblock release 0.0.3.98)

### Assembly pipeline (#498) — правильний job flow у тестах
- Додано helper `_complete_assembly_task()` у `tests/test_api.py` для імітації Worker-а з capability `video_assembly`, який виконав фінальний монтаж відео.
- Оновлено 4 падаючих тести для коректного проходження через новий статус `ASSEMBLY`:
  - `test_health_and_job_flow` — чекає ASSEMBLY, завершує assembly, потім VIDEO_PENDING_APPROVAL → READY
  - `test_regenerate_preserves_inputs_and_replaces_generated_artifacts` — завершує assembly перед перевіркою артефактів
  - `test_job_export_import_and_optimistic_lock` — завершує assembly перед video approval
  - `test_distributed_worker_result` — реєструє GPU worker з capabilities `image_generation`, `video_generation`, `video_assembly`; виконує і image generation, і assembly tasks
- Це відображає архітектурну зміну #498: весь фінальний монтаж (включно з нативним FFmpeg) виконується Worker-ом; CORE лише формує незмінну спробу, ставить в чергу і верифікує/імпортує результат.

### API routes snapshot
