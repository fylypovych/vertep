# Vertep 0.0.1.54

Виправлено та розширено диспетчеризацію генерації та публікації за Issue #4 (`i.0.0.0.1`) та Issue #30 (`i.0.0.0.28`).

## Генерація сценарію на Text Worker (Issue #4)
- Генерацію та перегенерацію сценарію винесено з CORE на Text Worker через task/dispatch. CORE більше не виконує LLM inference в основному шляху: він ставить `script`-задачу, а результат отримує через штатний task-result contract.
- Збережено поточний lifecycle `SCRIPT_QUEUED → SCRIPT_GENERATING → SCRIPT_PENDING_APPROVAL → SCRIPT_APPROVED` та revision loop.
- Коректно оброблено timeout, worker loss, retry, cancellation, `SCRIPT_FAILED`: повторна постановка задачі, requeue при heartbeat timeout, discard при cancel.
- Додано integration тест CORE → Text Worker → result → approval state.

## Publisher
- Publisher Worker виконує платформові адаптери (YouTube, TikTok та ін.) напряму або через `PUBLISHER_MOCK`, повертаючи `publication_receipt`.
- YouTube: прозорий refresh OAuth access-токена при 401 з використанням refresh token/client id/secret.
- CORE-side fallback публікації окремої платформи та розширення `/api/settings` integrations.

## Web UI — navigation, localization, accessibility, responsive (Issue #30)
- Уніфіковано українську термінологію навігації («Вузли»/«Вузол») у sidebar, header і routes; прибрано випадкові англійські мітки.
- Завершено route metadata: header title/subtitle відповідають URL для всіх роутів.
- Додано browser E2E: metadata header/sidebar, localization scan, collapsed sidebar з tooltips без overflow, loading → terminal state.
