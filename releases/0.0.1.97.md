# Vertep 0.0.1.97

## Міграція web-v2: VertepApiService → Domain Clients

Повна міграція Angular UI з монолітного `VertepApiService` (facade) на модульні domain clients.

### Нові сервіси
- `AuthApiService` — сесії, автентифікація, пароль, setup wizard
- `LogsApiService` — журнали подій
- `SettingsApiService` — секрети, інтеграції, Telegram, моделі
- `SecurityApiService` — перевірка безпеки, сертифікати
- `SystemApiService` — статус, health, метрики, оновлення, rolling update
- `WorkersApiService` — список worker-ів, heartbeat, ролі
- `JobsApiService` — CRUD задач, approve/reject/regenerate storyboard/script/video
- `ResourcesApiService` — персонажі, бренди, workflows, логотип
- `QueueApiService` — черги пайплайну

### Видалено
- `VertepApiService` (facade ~618 рядків)

### Зміни
- Main bundle: 223 kB → 205 kB
- Мігровано 28 компонентів
- ConfirmDialog: Tab focus trap
