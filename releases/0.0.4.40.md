# Vertep 0.0.4.40

- Меню панелі (рішення власника 23.11.2026): пункти сторінок модулів оголошує сам модуль у `ui.navigation` маніфесту (`label`, `group`, `admin_only`, `route`); CORE віддає їх лише для READY модулів (`GET /api/modules/navigation`). Майбутній модуль отримує пункт на свій підписаний UI автоматично; вбудовані сторінки панелі можуть задавати лише офіційні модулі, яким CORE їх відвів: characters → `/characters`, brands → `/brands`, publishing → `/published`.
- Вимкнений, несправний чи видалений модуль: пункту в меню немає (меню оновлюється без перезавантаження), guard не відкриває сторінку, а API CORE `/api/characters*`, `/api/brands*`, `/api/channels*` повертає 503 `module_is_not_active`; статичні пункти «Опубліковане», «Персонажі», «Бренди» прибрано з меню, порядок #518 збережено.
- Версії модулів: characters, brands, publishing — 0.0.4.16, web-ui — 0.0.4.24; у 0.0.4.39 `Component releases` відмовив у випуску web-ui, бо панель змінилася без підвищення версії.
- Тести: `test_queue_ready_inflight_have_task_fields` читає чергу з лімітом 500 і не залежить від кількості задач, лишених попередніми тестами; процесні й браузерні тести без контейнерів модулів вважають офіційні модулі активними (`tests/core_app_modules_active.py`, `tests/conftest.py`), нові тести меню й відмови API.
