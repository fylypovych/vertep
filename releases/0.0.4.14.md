# Vertep 0.0.4.14

- Інтерфейси модулів (Characters, Brands, Publishing, Monitoring, Storyboard) отримують дані через панель: розширення без власної мережі надсилає запит `postMessage`, панель виконує його лише в межах API цього модуля з сесією користувача; права й аудит, як і раніше, вирішують Gateway і CORE. Раніше інтерфейси модулів у панелі не могли завантажити дані.
- Storyboard (#501): браузерний сценарій правки на сторінці завдання з читанням нової версії в модулі; read-back версій, сцен, правки, погодження й хешів зображень після відновлення справжнім Backup Service.
- Web UI (#504): контейнерний тест оновлення й відкату панелі працює зі справжнім процесом CORE, реальною сесією та задачею Worker, узятою до відкату й завершеною після нього.
- Тест життєвого циклу MoneyPrinter налаштовує канал публікації через admin API відповідно до правила облікових даних каналу (#502).
