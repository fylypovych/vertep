# Vertep 0.0.3.40

Виправлення версії 0.0.3.39 та виконання #424–#426.

- Worker: вузол без поля `worker_api` більше не вважається несумісним; у 0.0.3.39 такі вузли не отримували задач.
- Backup: у розділі «Бекапи» є завантаження зашифрованої копії для адміністратора та нагадування про окреме зберігання ключа.
- Workflow: повернення до статичного режиму заборонене, поки є незавершені завдання динамічного режиму.
- Оновлення: генератор метаданих додає робочий ключ релізу за відкритою частиною й відмовляється зберігати приватні ключі в git-проєкті; маніфест оновлення містить `key_id`; документ церемонії виправлено.
- CI: `local-contracts` виконується в два потоки; `media-acceptance` має докладний вивід і таймер зависань.

Перевірка на реальному сервері не виконувалась.
