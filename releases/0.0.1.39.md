# Vertep 0.0.1.39

## Виправлення Web UI: script/storyboard approval та revision

- Виправлено `handleError` в `api.service.ts`: коректно витягує `detail` з `HttpErrorResponse.error.detail` та зберігає HTTP `status` для подальшої обробки 409 conflicts. Раніше Angular `HttpErrorResponse` не парсився, і текст помилки з бекенду не показувався користувачу.
- Додано обробку 409 conflict у `runAction` компонента `job-detail`: при отриманні 409 встановлюється `conflict` signal для відображення блоку «Конфлікт версії» з можливістю перезавантаження.
- Додано українські мітки `revision` (Правки) та `reject` (Відхилення) до `actionLabel` для коректного відображення toast-повідомлень.
- Оновлено browser E2E тест `test_script_backend_error_shows_error_and_no_crash`: перевіряється реальний текст помилки з бекенду замість загального «Помилка».

## Angular production build

- Додано конфігурацію production build в `angular.json`: `outputHashing`, `namedChunks`, `optimization`, `sourceMap`, `extractLicenses`, `defaultConfiguration`.

## Тести

- Додано тести для role services: CRUD, recreate, backup→wipe→restore для персонажів/брендів/workflow/jobs.
