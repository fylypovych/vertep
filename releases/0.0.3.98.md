# Vertep 0.0.3.98

## Виправлення тестів модулів

### Проблема
Тести Application Modules (`brands`, `storyboard`, `publishing`, `monitoring`, `web-ui`) не проходили через несумісність форматів `manifest.yaml`:
- **Flat формат** (characters): поля безпосередньо в корені YAML
- **Nested формат** (brands, storyboard, publishing, monitoring, web-ui): поля вкладені під ключем `module:`

Функція `bundled_manifest()` повертала сирий dict, а `ModuleManifest.from_dict()` очікував flat формат.

### Вирішення
1. **`core/module/lifecycle.py`**: `bundled_manifest()` тепер витягує `module` підсловник, якщо він є.
2. **`core/module/manifest.py`**: `ModuleManifest.from_dict()` автоматично мапить nested поля:
   - `runtime` → `placement.requires_gpu`, `resource_requirements`
   - `database` → `migrations`
   - `health_check` → `health`
   - `namespace` → `api.namespace`
   - `provides_capabilities` → `capabilities`
   - `requires_capabilities` → `requires`
   - Автоматично створює `container` для application модулів якщо відсутній
3. **Тести оновлено**: використовують `ModuleManifest.from_dict(bundled_manifest(...))` та прямого доступу до атрибутів (`manifest.name`, `manifest.kind`, `manifest.api`, `manifest.ui`, `manifest.placement`, `manifest.health`, `manifest.capabilities`, `manifest.dependencies`).
