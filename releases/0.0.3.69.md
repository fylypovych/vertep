# Vertep 0.0.3.69

- Browser E2E 0.0.3.68: приймання провайдерів обирає зовнішній MoneyPrinterTurbo явно; перевірку FFmpeg для Native перенесено в read model CORE, тож активація на Worker не залежить від FFmpeg на його хості, а повернення на Vertep Native не блокується готовністю.
- Security (#463): пошкоджений запис адміністратора з майстра першого запуску більше не обриває вхід `KeyError`; індикатор і фактичний вхід через `ADMIN_PASSWORD` узгоджені.
- Web UI (#464): збереження налаштувань публікації має межу очікування 30 с; завислий запит завершується локальним повідомленням про невідомий результат, без втрати вводу, з можливістю повтору; пізня відповідь не підміняє форму.
