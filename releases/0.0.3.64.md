# Vertep 0.0.3.64

- Health (#449): у журнал `health-history.jsonl` записуються лише нездорові події; ротація раз на UTC-добу (попередній день у `.jsonl.1`, старіший знищується), журнал попереднього формату один раз фільтрується до несправностей. Сторінка «Стан системи» показує «Несправності за останню добу»: повтори опитування однієї несправності згортаються в інцидент, окремі інциденти з перервою понад 60 секунд показуються окремо (`GET /api/health/history?changes=10`).
- Майстер (#445): службове поле `selected_roles` більше не показується як перевірка з помилкою на кроці Health Check.
- vertep remove (#446): видаляються лише Docker images, принесені Vertep (знімок наявних images до першого pull; без запису походження — лише images підписаного `images.json`); `--resume` через CLI знаходить незавершений журнал; після purge прибирається порожній layout і root; повторна інсталяція на збережених даних зберігає installation ID, bootstrap відмовляє при незавершеному видаленні.
