# Vertep 0.0.3.38

Виправлення падінь CI та Browser E2E версії 0.0.3.37.

- Оновлення: агент на хості знову звертається до CORE через HTTPS-проксі, бо `CORE_ADDRESS` є адресою всередині мережі Docker.
- Тести: перевірка повторної публікації рахує лише завантаження, а не запит посилання на пост; тест Update Center не вимагає CORE на тимчасовому хості.

Перевірка на реальному сервері не виконувалась.
