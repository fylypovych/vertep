# Vertep 0.0.1.65

## Мета
Виправлення реліз-блокуючого дефекту, що спричинив падіння release workflow 0.0.1.64 на CI.

## Зміни
- Виправлено `scripts/generate-root-metadata.py::sign_metadata`: невалідний `subprocess.Popen(..., check=True)` (Popen не підтримує `check`) замінено на `subprocess.run(check=True, input=..., capture_output=True)`. Це усуває `TypeError`, через який 4 тести `tests/test_key_lifecycle.py` падали на Linux CI.

## Перевірка
- `python -m compileall -q scripts/generate-root-metadata.py`: OK.
- Тести `tests/test_key_lifecycle.py` скипаються на Windows (потребують openssl/POSIX), тож повна верифікація виконується на Linux CI у `prepare`-вороті release workflow.
- `git diff --check`: без проблем.
