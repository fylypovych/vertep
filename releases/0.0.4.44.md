# Vertep 0.0.4.44

- Сторінка «Персонажі»: панель передає модулю Characters бренд-власника (`brand_id`) для створення, редагування, видалення, активації, референсів і співпраці — з поля «Власник (бренд)» або бренду персонажа; у 0.0.4.42 ці дії відхилялися модулем (422). web-ui — 0.0.4.26.
- Безпека: logout записує у відкликані сесії лише справжню чинну сесію; підроблений cookie більше не збільшує файл `revoked-sessions.json`.
- Тести: сценарій сторінки «Персонажі» (створення з брендом, перезавантаження, редагування, дубль) перенесено в `test_characters_browser_rbac.py` з реальним модулем; тест legacy-шляху з `test_browser_e2e.py` прибрано (Browser E2E 0.0.4.43); тест відмови для підробленого cookie.
