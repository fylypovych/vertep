# Vertep 0.0.1.68

## Мета
Виправлення shallow copy leak у хелпері `resign()` тесту key-lifecycle, який спричиняв мутацію оригінального `metadata` та падіння `validate(metadata, ...)` з помилкою signature threshold.

## Зміни
- `tests/test_key_lifecycle.py`: `resign()` тепер використовує `copy.deepcopy(metadata)` замість `dict(metadata)`. Попередній shallow copy дозволяв зміну `release_keys` через повернений словник проникати в оригінальний `metadata`, що робило canonical невідповідним підписам і викликало `RuntimeError("Root metadata signature threshold was not met")` при подальшому `validate(metadata, ...)`.

## Перевірка
- `python -m compileall -q tests/test_key_lifecycle.py`: OK.
- `pytest --collect-only tests/test_key_lifecycle.py`: 4 tests collected.
- Повна верифікація openssl-тестів виконується на Linux CI у `prepare`-вороті release workflow.
