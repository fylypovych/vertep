# Vertep 0.0.1.5

Впроваджено Provider / Adapter Layer та опційні open-source движки (фази 1–6 open-source аудиту).

**Phase 1 — Provider Layer:**
- Додано формалізовані інтерфейси (`LLMProvider`, `ImageProvider`, `VideoProvider`, `TTSProvider`, `AssemblyProvider`, `ComputeProvider`, `PublisherProvider`, `VideoEngine`) у `adapters/providers/base.py`.
- Додано лазливий registry `providers` та фабрики (`get_providers`, `replace`) у `adapters/providers/__init__.py`.
- Переведено `core/pipeline.py`, `core/script_agent.py`, `worker/service.py`, `worker/role_executor.py` на `providers.*` та абстрактні інтерфейси замість прямих викликів `FFmpegAdapter` / `ComfyUIAdapter`.

**Phase 2 — LLM та TTS:**
- Додано `adapters/llm_clients.py`: Ollama та OpenAI-сумісний клієнти (вибір через `VERTEP_LLM_PROVIDER`, ключ `OPENAI_API_KEY`/`OPENAI_COMPAT_*`).
- Додано `adapters/providers/tts_backends.py`: Piper (MIT) та Kokoro (Apache-2.0) через `TTS_PROVIDER`.
- `ScriptAgent` тепер використовує backend-agnostic LLM-клієнт.

**Phase 3 — Live Publisher адаптери:**
- Створено `publishers/base.py`, `publishers/transport.py` (HttpTransport, FakeTransport, check_response).
- Оновлено live адаптери YouTube, TikTok, Facebook, Instagram, Threads на транспортний шар та публікацію відео.
- Розширено `publishers/__init__.py` (`LIVE_PUBLISHERS`) та `adapters/publisher.py`.
- `core/app.py` використовує `providers.publisher()` замість `PUBLISHERS`.

**Phase 4 — Опційний ComfyUI-Distributed:**
- Додано `adapters/providers/compute_backends.py`: `ComfyUIDistributedProvider`; активація лише за `VERTEP_COMPUTE_PROVIDER=comfyui-distributed` та `COMFYUI_DISTRIBUTED_URL`, інакше fallback на `vertep-worker`.

**Phase 5 — VideoEngine:**
- Додано `adapters/providers/video_engines.py`: `native` (FFmpeg) за замовчуванням, опційні `money-printer` / `shortgpt` за `VERTEP_VIDEO_ENGINE` та URL.
- `finalize_job` тепер рендерить через `providers.video_engine()` з єдиним Job-циклом.

**Phase 6 — Документація та hardening:**
- Додано `provider_matrix()` та інтегровано в `/api/status` (`providers`).
- Web UI v2 тепер є за замовчуванням на `/`, класичний v1 на `/v1` (SPA-fallback, перемикач у header).
- У Налаштуваннях додано панель «Движки обробки (backends)».
- Оновлено `AGENTS.md` (розділ 28), `README.md`, `.env.example`.
- Додано `docs/architecture/open-source-audit.md`.

**Інфраструктура:**
- Додано `web-v2/dist/` та `web-v2/.angular/` до `.gitignore` та прибрано build-артефакти з трекінгу.
- Додано тести: `test_providers.py`, `test_llm_tts_providers.py`, `test_publisher_live_adapters.py`, `test_compute_distributed.py`, `test_video_engines.py`, `test_provider_matrix.py`.
