# Vertep 0.0.4.64

- Модулі на CORE: модулі, вбудовані в реліз (Бренди, Персонажі, Моніторинг, Сторіборд), тепер запускаються системним виконавцем — у 0.0.4.63 воркер мовчки відкидав їхні пакети без підпису. CORE віддає маніфест свого релізу (`core/module/gateway.py`), воркер бере маніфест зі свого релізу й журналює відмови (`worker/application_supervisor.py`), хост бере маніфест і закріплений образ лише з підписаного runtime bundle `runtime/module-manifests.json`, а копію з запиту воркера ігнорує (`scripts/apply-deployment.py`, `scripts/build-runtime-bundle.py`, крок у `publish-release` `.github/workflows/release.yml`).
- LAB (#491): підключення лабораторії до Vertep одноразовою командою з «Налаштування → Система → Підключити лабораторію» — bootstrap перевіряє відбиток сертифіката CORE, ключ панелі створюється на VM, CORE підписує сертифікат панелі своїм CA лише на хост адреси панелі, видає токен GPU-оренди й запам'ятовує адресу панелі; адреса Vertep, адреса оренди і CA CORE записуються автоматично; «Відключити лабораторію» відкликає доступ (`core/lab_connection.py`, `/api/lab/connection-token`, `/api/lab/connect`, `/api/lab/connection`, `core/api/lab_lease.py`, `core/api/auth.py`, `bootstrap-lab.sh`, `web-v2/src/app/settings/sections/system-info.section.ts`). Bootstrap LAB більше не просить замінювати сертифікат вручну і не друкує токен власника.
- Bootstrap: ключі apt-репозиторіїв NVIDIA Container Toolkit і ROCm записуються з правами 0644 (`gpg --batch --yes`), бо через `umask 077` apt відкидав репозиторій як непідписаний (`bootstrap.sh`, `tests/test_bootstrap_apt_keyrings.py`).
- Медіаоперації (#548, #551): додаткові задачі LoRA та lip-sync для наявного Job із власною чергою, перевіркою референсів і контракту голосу та імпортом результату (`core/api/media_operations.py`, `core/api/tasks.py`, `core/api/task_results.py`, `core/models.py`, `core/runtime.py`, `worker/service.py`, `worker/role_executor.py`); MuseTalk на закріпленому commit і CUDA 11.8, GPU для `lora-trainer`/`musetalk` у `deploy/docker-compose.nvidia.yml`.
- LAB: обов'язковий контракт задачі з 4 пунктів (`lab/task_contract.md`, `lab/task_contract.py`; перевірка в `lab/orchestrator.py`, CLI й API, `AGENTS.md` §4.6, `docs/lab.md`); оцінювання моделей у приватному мережевому просторі з одним endpoint моделі (`lab/eval_network.py`, `lab/eval_runner.py`).
- Інше: експорт OTIO (`modules/storyboard/otio_export.py`), шаблони Wan2.2 14B, коди й переклади нових помилок API (`core/api_error_codes.json`, `web-v2/src/app/core/i18n/api-errors.ts`).
- Компонентні релізи: lab 0.0.4.38, web-ui 0.0.4.37, storyboard 0.0.4.19.
