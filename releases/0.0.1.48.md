# Vertep 0.0.1.48

## Telegram approval flow для сценаріїв та відео

- Додано callback-хендлери `sc_ok`, `sc_regen`, `sc_edit`, `sc_reject` для затвердження/правки/перегенерації/відхилення сценаріїв через Telegram.
- Додано callback-хендлери `vid_ok`, `vid_regen`, `vid_edit`, `vid_reject` для затвердження/правки/перегенерації/відхилення відео через Telegram.
- Реалізовано `render_script()` для форматування сценарію у Telegram-friendly chunks.
- Додано inline-клавіатури `script_keyboard()` та `video_approval_keyboard()`.
- Реалізовано `_send_script_approval_to_telegram()` для надсилання сценарію на затвердження адміністраторам.
- Додано `send_video_for_approval()` для надсилання зібраного відео на затвердження.
- Реалізовано `approve_video()`, `request_video_revision()`, `regenerate_video()` у pipeline.
- Розширено `JOB_STATE_TRANSITIONS`: `VIDEO_APPROVED → VIDEO_READY`.
- Оновлено `_prepare_and_dispatch()`: обробка `VIDEO_PENDING_APPROVAL` та `VIDEO_REVISION_REQUESTED`.
- Додано тести `tests/test_telegram_approval_flow.py`: клавіатури, рендеринг, обробка callback, pipeline, ідемпотентність, введення тексту правок.
