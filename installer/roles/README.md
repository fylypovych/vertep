# Розширення ролей інсталятора

Нова роль додається без змін `role-plan.py`:

1. Додайте роль із пакетами та сервісами до `installer/manifest.json`.
2. За потреби додайте профіль, який об’єднує кілька ролей через `includes`.
3. Для спеціального налаштування створіть `installer/roles/<profile>.sh`.

Hook отримує корінь репозиторію першим аргументом і назву профілю другим. Він має бути
ідемпотентним: повторний запуск не повинен псувати наявну конфігурацію. Інсталятор викликає
hook через `bash`, тому executable-біт не є обов’язковим.
